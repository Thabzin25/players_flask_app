# Football Scouting System
A Flask-based football scouting platform designed to help scouts and clubs manage player information, reports, and analytics.

## Features
- Player management
- Scout reports
- Club dashboards
- Authentication system
- Database integration

## Tech Stack
- Python
- Flask
- HTML/CSS
- JavaScript
- MongoDB
- Git/GitHub
